# PNP

Put pick-and-place and centroid exports here.

Recommended contents:

- XLSX or CSV placement exports
- Assembly coordinate files
- Placement notes if the board needs special handling

Keep this folder aligned with the same board revision as the BOM and Gerber set.

Current contents:

- `PickAndPlace_PCB2_2026_05_20.xlsx` - EasyEDA Pro pick-and-place export for PCB2
